# Map base images (placeholders for the map mockups)

Screenshots of Google Maps (default light layer), cropped; UI chrome, personal data and third-party business labels removed.
- `europe-z5.png` 1830x1000: Europe, zoom ~5 (200 km scale). Cluster circles and country-level spread.
- `city-z12.png` 1580x1000: Berlin, zoom ~12 (2 km scale). Single markers and marker cards. Cropped so the left 400 px (our side panel) covers the cleaned-out stadium label.
Google logo and "Map data" line are kept on purpose. Product uses Google Maps; these are honest placeholders.
Bottom-right smudge = cleaned-out zoom controls; our own controls sit on top of it.
