# Role and status symbols (library)

Ready-made, openly licensed line icons for the profile hero background (faded, 9 %) and small status slots.
Codes: R referee, I intermediary, F football fan, M manager / official, S without club or no crest, T retired.
All files are normalised: colour #5b6560, stroke width 1.5 (Lucide in 24 px units, Phosphor regular is about the same weight at 256 px), single family look.
